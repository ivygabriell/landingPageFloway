# Telas aprovadas

O registro das telas aprovadas pela pessoa no Figma (decisão 015 do método). **Neste projeto, as telas ficam no Penpot** (decisão da pessoa em 2026-11-22): arquivo `New File 4`, página `Landing Floway` (file-id `7b7d55f9-965b-8000-8008-fa27170dff9f`, page-id `1fcd2bb1-9bc7-80d1-8008-fcb784618a4f`); os links abaixo levam o id do quadro (board). A cada aprovação, o Designer (sem o modo com especialistas, a Lead) acrescenta, num PR: uma captura por tela e estado (`R-NN-nome-estado.png`), a data e o link do frame, e atualiza `tokens.json` com os tokens do Figma. O código segue só a versão registrada aqui; toda mudança de tela começa no Figma. Projeto sem interface: escreva "sem interface" nesta linha e deixe a pasta assim.
